# Data Directory

This directory contains input datasets for the experiments.

## Expected Structure

```
data/
  sample/                     Demo dataset (ADRA2B target, ~10k molecules)
    library.csv               SMILES + docking + Boltz-2 scores + molecule IDs
    binders.csv               21 experimentally validated binders
    fingerprints/             Pre-computed molecular fingerprints
      morgan_2048.npz         (n, 2048) uint8 - Morgan radius-3 fingerprints
      atompair.npz            (n, 2048) uint8 - AtomPair fingerprints
      descriptors.npy         (n, 15) float32 - RDKit molecular descriptors
      valid.npy               (n,) bool - which SMILES parsed successfully
      canonical_smiles.npy    (n,) object - RDKit-canonicalized SMILES
```

Bit vectors ship compressed as `.npz` (single array under the key `data`);
`lib/features.py` loads `.npz` in preference to `.npy` and casts to float32 on
read. The uncompressed `.npy` equivalents are gitignored.

## library.csv Columns

| Column | Description |
|---|---|
| `smiles` | Canonical SMILES string |
| `zincid` | Unique molecule identifier (ZINC ID) |
| `consensus_score` | Oracle score: 0.5 * normalized_docking + 0.5 * normalized_boltz_prob |
| `docking_score` | UniDock docking score (more negative = better) |
| `boltz_prob` | Boltz-2 binding probability |
| `is_active` | Experimental binder flag (1/0), present for molecules with in-vitro data |

## Full Data Sources

The demo dataset is a subsample of the full ADRA2B library. Full datasets (not included due to size):

| Dataset | Molecules | Size | Source |
|---|---:|---|---|
| BoltzDock-1M (per target) | ~1M | ~200 MB | Computed on ROMEO HPC cluster |
| Full docking libraries | 7.9M-468M | 1-53 GB | LSD DockingResults (Shoichet lab screens) |
| Fingerprint caches | ~1M per target | 16 GB | Generated by `lib/features.py` |
| AmpC 10M | 10M | ~82 GB (packed) | Subsampled from full AmpC screen |

To reproduce full results, obtain the BoltzDock-1M datasets and place each target's
CSV in `data/boltzdock_1M/{TARGET}_1M_unidock_labeled_consensus_scores.csv`.

## Regenerating Fingerprints

If fingerprints are not provided, generate them from SMILES:

```python
from lib.features import featurize_batch
import numpy as np
import pandas as pd

df = pd.read_csv("data/sample/library.csv")
result = featurize_batch(df["smiles"].tolist(), n_workers=4)

fp_dir = "data/sample/fingerprints"
np.savez_compressed(f"{fp_dir}/morgan_2048.npz", data=result.morgan)
np.savez_compressed(f"{fp_dir}/atompair.npz", data=result.atompair)
np.save(f"{fp_dir}/descriptors.npy", result.descriptors)
np.save(f"{fp_dir}/valid.npy", result.valid)
np.save(f"{fp_dir}/canonical_smiles.npy", result.canonical_smiles)
```
